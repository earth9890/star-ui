# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.0.2] - 2024-01-20

### Added
- Enhanced Input component with flexible label positioning (top, bottom, left, right)
- Label and required props to Input component Storybook documentation
- Icons now properly integrate within addons when both are present

### Fixed
- Icon and addon overlap issues in Input component
- Left icon rendering issue in Input component
- React hooks usage in Storybook stories
- ESLint warnings in ThemeProvider

### Changed
- Updated Input component TypeScript types for new label positions
- Improved Input component layout structure for better flexibility

## [0.0.1] - 2024-01-19

### Added
- Initial release of Star UI component library
- Button component with multiple variants and sizes
- Badge component with semantic color support
- Card component with composable structure
- Input component with comprehensive features
- Theme system with dark mode support
- Tailwind CSS integration
- TypeScript support
- Storybook documentation
